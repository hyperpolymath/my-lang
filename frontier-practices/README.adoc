====
**This directory was previously named `my-lang/7-tentacles/`.** It has been renamed to
`my-lang/frontier-practices/` to reflect its real role and to resolve a long-standing
name collision with the separate curriculum source of truth that lived as a submodule of
`nextgen-languages/`.

**New mental model:**

* **`tentacles-agentic-syllabus`** (top-level repo, ex `hyperpolymath/7-tentacles`) — the
  curriculum source of truth: syllabus, aspect-agents, kin framework, and the (to be built)
  Me runtime projector. Applies to every language in the hyperpolymath ecosystem.
* **This directory** (`my-lang/frontier-practices/`) — the **my-lang-specific applied layer**.
  Worked examples in me-language, tabletop games tuned to my-lang concepts, teacher guides
  that show how to deliver the syllabus *in my-lang specifically*, lessons that walk
  learners through my-lang primitives. It consumes the syllabus; it does not own the
  syllabus.

This pattern parallels `~/Desktop/Frontier_Programming_Practices_AffineScript/` for
AffineScript. Every language may eventually have its own `frontier-practices/` applied
layer that consumes the same common curriculum.

**Also outdated below:**

* The "Ages 8-18" framing is narrower than the real audience (anyone from 8-year-olds to
  senior professors).
* "4 language dialects (Me, Solo, Duet, Ensemble)" is wrong. Real My-Lang dialects are
  **three, nested**: `Solo ⊂ Duet ⊂ Ensemble`. Me is not a fourth dialect — it is an
  on-the-fly agent-generated projection over the dialect hierarchy, and it is specified in
  `tentacles-agentic-syllabus/me/README.adoc`.
* The `7` in "7 cephalopod mascots" is no longer load-bearing. The count of agents may
  grow or shrink without invalidating the design.

A full rewrite of this README to reflect the evolved architecture is a follow-up task.
The content below is retained until then.

*Teaching Compiler Architecture to Ages 8-18 Through Progressive Reveal & Playful Mascots*

image::assets/mascots/octopus.svg[Seven Tentacles Logo,200,align="center"]

== The Vision

Seven Tentacles is a *radically innovative 10-year learning framework* that teaches university and graduate-level compiler architecture concepts to children aged 8-18 without them realizing it.

=== The Core Insight

Kids learn by playing games with colorful mascots. At age 8, they meet "Speedy Red" and play racing games. At age 16, they discover that "Speedy Red" has been teaching them about recursive descent parsing, and Red now goes by "Performance Agent Red." They've been learning compilers for 8 years without noticing.

=== The Stack

* **7 cephalopod mascots** (octopus agents) — each teaches one compiler component
* **4 language dialects** (Me, Solo, Duet, Ensemble) — matching their age/maturity
* **Progressive reveal system** — concepts introduced as games, revealed as CS
* **10-year narrative journey** — Cuttle → Squidlet → Duet → Octopus

=== Target Outcome

16-year-olds with *graduate-level understanding* of:

* Parsing & lexical analysis
* Concurrency & async/await
* Type systems & affine types
* AST construction & manipulation
* Audit trails & verification
* Compile-time evaluation
* Language governance & policy enforcement

== The Seven Agents

[cols="1,2,3"]
|===
|Agent |Role |Teaches

|🔴 Red |The Parser |Lexical analysis → Parsing → Syntax trees
|🟠 Orange |The Concurrency Engine |Async/await, scheduling, event loops
|🟡 Yellow |The Type System |Type systems, affine types, memory safety
|🟢 Green |The AST Architect |Abstract syntax trees, code representation
|🔵 Blue |The Auditor |Verification, auditing, tracing, debugging
|🟣 Indigo |The Metaprogrammer |Compile-time evaluation, macros, reflection
|🟤 Violet |The Governance System |Language design, policy enforcement, ethics
|===

== The Cephalopod Journey

[horizontal]
🐚 Cuttle (8-12):: Baby cuttlefish. One tentacle at a time. Visual "Me Language."
🦑 Squidlet (13-14):: Adolescent squid. Names change. CS concepts emerge.
🦑🦑 Duet (15):: Two squid dancing. Explicit agent collaboration.
🐙 Octopus (16+):: Full orchestration. Build complete compilers.
