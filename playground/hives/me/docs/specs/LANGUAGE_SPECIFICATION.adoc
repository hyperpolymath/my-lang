=== Introduction

My Language is a family of four programming language dialects designed
for progressive complexity:

* *Me*: Educational HTML-like language for children
* *Solo*: Core systems language with affine types and safety features
* *Duet*: Solo + neurosymbolic AI integration +
* *Ensemble*: Multi-agent orchestration and collaboration

==== Design Principles

[arabic]
. *Progressive Complexity*: Start simple, add features as needed
. *Safety First*: Strong type system, affine types, contracts
. *AI Integration*: First-class support for AI-assisted development
. *Performance*: Zero-cost abstractions, compile-time execution
. *Ergonomics*: Clear syntax, helpful error messages

=== Solo Specification

==== Syntax Overview

[source,solo]
----
fn main() {
    println("Hello, World!");
}
----

==== Core Features

===== 1. Variables and Types

[source,solo]
----
let x: i32 = 42;
let mut counter = 0;
let tuple: (i32, str) = (1, "hello");
----

===== 2. Functions

[source,solo]
----
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn generic<T>(value: T) -> T {
    value
}
----

===== 3. Control Flow

[source,solo]
----
if condition {
    // ...
} else {
    // ...
}

match value {
    1 => "one",
    2 => "two",
    _ => "other"
}

for i in 0..10 {
    println(i);
}
----

===== 4. Structs and Enums

[source,solo]
----
struct Point {
    x: i32,
    y: i32
}

enum Option<T> {
    Some(T),
    None
}
----

===== 5. Traits

[source,solo]
----
trait Printable {
    fn print(&self);
}

impl Printable for Point {
    fn print(&self) {
        println("({}, {})", self.x, self.y);
    }
}
----

===== 6. Contracts

[source,solo]
----
fn divide(a: i32, b: i32) -> i32
where
    pre b != 0,
    post result * b == a
{
    a / b
}
----

===== 7. Affine Types

[source,solo]
----
struct FileHandle {
    handle: affine File
}

impl FileHandle {
    fn read(self) -> str {
        // Consumes self, ensuring single use
        self.handle.read_all()
    }
}
----

===== 8. Async/Await

[source,solo]
----
async fn fetch_data(url: str) -> str {
    let response = http::get(url).await;
    response.body()
}
----

===== 9. Comptime

[source,solo]
----
comptime fn factorial(n: u64) -> u64 {
    if n <= 1 { 1 } else { n * factorial(n-1) }
}

const FACT_10: u64 = comptime factorial(10);
----

=== Duet Specification

Duet extends Solo with neurosymbolic AI integration.

==== AI Synthesis

[source,duet]
----
@synth(spec: |x| x * 2)
fn double(x: i32) -> i32;

@synth(examples: [(0,0), (1,1), (2,4), (3,9)])
fn square(x: i32) -> i32;
----

==== AI Verification

[source,duet]
----
@verify(property: |x, result| result >= 0)
fn abs(x: i32) -> i32 {
    if x < 0 { -x } else { x }
}
----

==== Intent Programming

[source,duet]
----
fn main() {
    let sorted = intent("sort this list", {
        inputs: [5, 2, 8, 1],
        outputs: [i32]
    });
}
----

==== AI Optimization

[source,duet]
----
#[ai_optimize(strategy: "minimize_latency")]
fn fibonacci(n: u64) -> u64 {
    if n <= 1 { n } else { fibonacci(n-1) + fibonacci(n-2) }
}
----

==== Hybrid Reasoning

[source,duet]
----
fn classify(data: Data) -> Label {
    hybrid {
        symbolic: rule_based_classifier(data),
        neural: ml_classifier(data),
        fusion: weighted(0.3, 0.7)
    }
}
----

=== Ensemble Specification

Two variants exist:

==== Variant A: Agent as Construct

[source,ensemble]
----
agent ReporterAgent {
    state {
        persistent topic: str;
        ephemeral sources: Vec<Source>;
    }

    capabilities {
        research(topic: str) -> Article: action;
    }

    goals {
        high investigate: find_stories();
    }

    communication {
        on ArticleRequest {
            let article = research(topic);
            send article to sender;
        }
    }
}

workflow Newroom {
    stages {
        ReporterAgent -> EditorAgent -> FactCheckerAgent -> PublisherAgent
    }

    coordination {
        consensus(threshold: 0.85) on verification;
    }
}
----

==== Variant B: Mode-Based

Regular Duet code with attributes:

[source,duet]
----
#![ensemble(mode: "collaborative", agents: ["reporter", "editor"])]

#[agent("reporter")]
fn research(topic: str) -> Article {
    // Implementation
}

#[workflow({
    "research": { agent: "reporter" },
    "edit": { agent: "editor", depends_on: ["research"] }
})]
fn pipeline(topic: str) -> Article {
    // Pipeline logic
}
----

Configuration in `+my.toml+`:

[source,toml]
----
[ensemble]
mode = "collaborative"

[[ensemble.agents]]
name = "reporter"
role = "research"
model = "claude-3-opus"
----

=== Type System

==== Primitive Types

* Integers: `+i8+`, `+i16+`, `+i32+`, `+i64+`, `+i128+`, `+isize+`
* Unsigned: `+u8+`, `+u16+`, `+u32+`, `+u64+`, `+u128+`, `+usize+`
* Floats: `+f32+`, `+f64+`
* Boolean: `+bool+`
* Character: `+char+`
* String: `+str+`
* Unit: `+()+`
* Never: `+!+`

==== Compound Types

* Tuples: `+(T1, T2, ...)+`
* Arrays: `+[T; N]+`
* Slices: `+[T]+`
* References: `+&T+`, `+&mut T+`
* Functions: `+fn(T1, T2) -> R+`

==== Generic Types

[source,solo]
----
struct Container<T> {
    value: T

fn identity<T>(x: T) -> T { x }
----

The compiler infers types where possible:

=== Affine Types

Affine types ensure resources are used at most once.

==== Declaration

[source,solo]
----
struct Resource {
    data: affine Handle
}
----

==== Rules

[arabic]
. Affine values can be used at most once
. No implicit copying
. Explicit consumption required
. Compiler enforces linearity

==== Example

[source,solo]
----
fn use_resource(r: Resource) {
    r.data.consume();  // OK: consumed once
    // r.data.consume();  // ERROR: already consumed
}
----

=== Contract System

==== Preconditions

[source,solo]
----
fn sqrt(x: f64) -> f64
where
    pre x >= 0.0
{
    // Implementation
}
----

==== Postconditions

[source,solo]
----
fn abs(x: i32) -> i32
where
    post result >= 0
{
    if x < 0 { -x } else { x }
}
----

==== Invariants

[source,solo]
----
impl BankAccount
where
    invariant self.balance >= 0
{
    fn withdraw(&mut self, amount: i32) -> bool {
        if self.balance >= amount {
            self.balance -= amount;
            true
        } else {
            false
        }
    }
}
----

=== Concurrency Model

==== M:N Threading

Green threads multiplexed over OS threads:

[source,solo]
----
async fn task() {
    // Runs on M:N scheduler
}

fn main() {
    spawn_task(task());
}
----

==== Thread Safety

* `+Send+`: Can be sent across threads
* `+Sync+`: Can be shared across threads
* Compiler enforces thread safety

==== Synchronization

[source,solo]
----
let mutex = Mutex::new(0);
let guard = mutex.lock();
*guard += 1;
----
